Миниконфигурация для новичков в 1С -старт для тех, кто только знакомится с платформой. На наглядном примере складского учёта вы освоите:

-работу с иерархическими справочниками (на примере «Контрагентов»);

-ведение номенклатурного справочника («Товары»);

-автоматический расчёт стоимости товаров в документах поступление и реализация;

- регистр накопления остатков "Остатки товаров";

- Регистр Оборотов "Продажи";

- Контроль остатков и себестоимости по партиям при проведении документа "Реализация";

- Отчет о продажах.;

- Условные оформления в динамических списках;

- регламентное задание.

Как открыть файл - открываем 1С предприятие в режиме конфигуратор, в программе в верхнем правом углу выбираем вкладку конфигурация, потом выбираем вкладку "Загрузить конфигурацию из файлов" и выбираете эту папку в директории выбора
