Миниконфигурация для новичков в 1С -старт для тех, кто только знакомится с платформой. На наглядном примере складского учёта вы освоите:

-работу с иерархическими справочниками (на примере «Контрагентов»);

-ведение номенклатурного справочника («Товары»);

-автоматический расчёт стоимости товаров в документах поступление и реализация;

- регистр накопления остатков "Остатки товаров";

- Регистр Оборотов "Продажи";

- Контроль остатков и себестоимости по партиям при проведении документа "Реализация";

- Методы списания партий - Фифо, Лифо, По средней,

- Отчет о продажах.;

- Условные оформления в динамических списках;

- Регламентное задание  которое в конце месяца запрещает менять данные, и запрещает записывать проведенные документы "Реализация" по периоду.

- Регламентное задание которое проверяет справочник "Товары" и записывает данные в справочник "ТоварыБезДвижения" те элементы справочника которые не использовались в движениях 6 месяцев, перед этим очищая элементы справочника "ТоварыБезДвижения";

- Обработка для проверки регламентного задания.

- RLS

1-я база Mini-scladSRV - основная база сервер для проверки - содержит HTTP-запросы - 1-й для записи элементов справочника "Товары" на сервере по отбору по коду, 2-й получение с базы клиента элемент справочника "Товары".

2-я база Mini-scladCLT - база клиент - в справочнике "Товары" есть 2 команды - первая команда получает данные справочника "Товары" по отбору по коду, 2-я команда создает на сервере элемент справочника "Товары" со всемми данными на форме элемента справочника "Товары" клиента.

Как открыть файл - открываем 1С предприятие в режиме конфигуратор, в программе в верхнем правом углу выбираем вкладку конфигурация, потом выбираем вкладку "Загрузить конфигурацию из файлов" и выбираете эту папку в директории выбора
